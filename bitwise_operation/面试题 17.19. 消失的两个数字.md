[面试题 17.19. 消失的两个数字](https://leetcode.cn/problems/missing-two-lcci/)

给定一个数组，包含从 1 到 N 所有的整数，但其中缺了两个数字。你能在 O(N) 时间内只用 O(1) 的空间找到它们吗？

以任意顺序返回这两个数字均可。

**示例 1：**

```
输入：[1]
输出：[2,3]
```

**示例 2：**

```
输入：[2,3]
输出：[1,4]
```

**提示：**

- `nums.length <= 30000`



## 解法：位运算

- 前提：[268. 丢失的数字](https://leetcode.cn/problems/missing-number/)、[260. 只出现一次的数字 III](https://leetcode.cn/problems/single-number-iii/)
- 时间复杂度：O(n)
- 空间复杂度：O(1)

```c
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* missingTwo(int* nums, int numsSize, int* returnSize) {
    unsigned xor = 0;
    for (int i = 1; i <= numsSize + 2; ++i) xor ^= i;
    for (int i = 0; i < numsSize; ++i) xor ^= nums[i];

    xor &= -xor;

    int* ret = (int*)calloc(2, sizeof(int));
    for (int i = 0; i < numsSize; ++i)
    {
        if ((nums[i] & xor) == 0) ret[0] ^= nums[i];
        else ret[1] ^= nums[i];
    }

    for (int i = 1; i <= numsSize + 2; ++i)
    {
        if ((i & xor) == 0) ret[0] ^= i;
        else ret[1] ^= i;
    }

    *returnSize = 2;
    return ret;
}
```
