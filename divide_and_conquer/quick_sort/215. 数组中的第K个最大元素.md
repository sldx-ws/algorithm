[215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `**k**` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

 

**示例 1:**

```
输入: [3,2,1,5,6,4], k = 2
输出: 5
```

**示例 2:**

```
输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
```

 

**提示：**

- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`



## 解法：快速选择

- 时间复杂度：O(n)
- 空间复杂度：O(1)

```c
void swap(int* pa, int* pb)
{
    int tmp = *pa;
    *pa = *pb;
    *pb = tmp;
}

void partition(int* nums, int left, int right, int* outLeft, int* outRight)
{
    int random = rand();
    int pivot = nums[left + rand() % (right - left + 1)];
    int i = left - 1, j = left, k = right + 1;
    
    while (j < k)
    {
        if (nums[j] < pivot)
            swap(&nums[++i], &nums[j++]);
        else if (nums[j] == pivot)
            ++j;
        else 
            swap(&nums[--k], &nums[j]);
    }

    *outLeft = i;
    *outRight = k;
}

int quick_select(int* nums, int left, int right, int x)
{
    if (left >= right) return nums[left];

    int outLeft, outRight;
    partition(nums, left, right, &outLeft, &outRight);
    if (outLeft < x && x < outRight)
        return nums[x];
    else if (left <= x && x <= outLeft)
        return quick_select(nums, left, outLeft, x);
    else
        return quick_select(nums, outRight, right, x);
}

int findKthLargest(int* nums, int numsSize, int k) {
    return quick_select(nums, 0, numsSize - 1, numsSize - k);
}
```
