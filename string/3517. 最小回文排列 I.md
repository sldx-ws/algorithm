[3517. 最小回文排列 I](https://leetcode.cn/problems/smallest-palindromic-rearrangement-i/)

给你一个 **回文** 字符串 `s`。

返回 `s` 的按字典序排列的 **最小** 回文排列。

如果一个字符串从前往后和从后往前读都相同，那么这个字符串是一个 **回文** 字符串。

**排列** 是字符串中所有字符的重排。

如果字符串 `a` 按字典序小于字符串 `b`，则表示在第一个不同的位置，`a` 中的字符比 `b` 中的对应字符在字母表中更靠前。
如果在前 `min(a.length, b.length)` 个字符中没有区别，则较短的字符串按字典序更小。

 

 

**示例 1：**

**输入：** s = "z"

**输出：** "z"

**解释：**

仅由一个字符组成的字符串已经是按字典序最小的回文。

**示例 2：**

**输入：** s = "babab"

**输出：** "abbba"

**解释：**

通过重排 `"babab"` → `"abbba"`，可以得到按字典序最小的回文。

**示例 3：**

**输入：** s = "daccad"

**输出：** "acddca"

**解释：**

通过重排 `"daccad"` → `"acddca"`，可以得到按字典序最小的回文。

 

**提示：**

- `1 <= s.length <= 10^5`
- `s` 由小写英文字母组成。
- 保证 `s` 是回文字符串。



## 解法1：排序

```c
int cmp(const void* pa, const void* pb)
{
    return *(char*)pa - *(char*)pb;
}

char* smallestPalindrome(char* s) {
    int len = strlen(s);
    char* ret = (char*)malloc((len + 1) * sizeof(char));

    qsort(s, len / 2, sizeof(char), cmp);  // 只排序前半部分
    strcpy(ret, s); 
    
 	// 后半部分镜像
    for (int i = 0; i < len / 2; ++i)
    {
        ret[len - 1 - i] = s[i];
    }

    return ret;
}
```

## 解法2：计数排序

```c
char* smallestPalindrome(char* s) {
    int len = strlen(s);
    int hash[26] = { 0 };

    char* ret = (char*)malloc((len + 1) * sizeof(char));
    
    for (int i = 0; i < len / 2; ++i)
    {
        ++hash[s[i] - 'a'];
    }

    int idx = 0;
    for (int i = 0; i < 26; ++i)
    {
        if (hash[i] != 0)
        {
            for (int j = 0; j < hash[i]; ++j)
            {
                ret[idx++] = (char)(i + 'a');
            }
        }
    }

    if (len % 2 != 0) ret[idx++] = s[len / 2];

    // 镜像
    for (int i = len / 2 - 1; i >= 0; --i)
    {
        ret[idx++] = ret[i];
    }

    ret[len] = '\0';

    return ret;
}
```
