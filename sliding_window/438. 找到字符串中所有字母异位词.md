[438. 找到字符串中所有字母异位词](https://leetcode.cn/problems/find-all-anagrams-in-a-string/)

给定两个字符串 `s` 和 `p`，找到 `s` 中所有 `p` 的 **异位词**的子串，返回这些子串的起始索引。不考虑答案输出的顺序。



 **示例 1:**

```
输入: s = "cbaebabacd", p = "abc"
输出: [0,6]
解释:
起始索引等于 0 的子串是 "cba", 它是 "abc" 的异位词。
起始索引等于 6 的子串是 "bac", 它是 "abc" 的异位词。
```

 **示例 2:**

```
输入: s = "abab", p = "ab"
输出: [0,1,2]
解释:
起始索引等于 0 的子串是 "ab", 它是 "ab" 的异位词。
起始索引等于 1 的子串是 "ba", 它是 "ab" 的异位词。
起始索引等于 2 的子串是 "ab", 它是 "ab" 的异位词。
```

 

**提示:**

- `1 <= s.length, p.length <= 3 * 10^4`
- `s` 和 `p` 仅包含小写字母



## 解法：滑动窗口

- 时间复杂度：O(n + m)
- 空间复杂度：O(1)

```cc
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* findAnagrams(char* s, char* p, int* returnSize) {
    int n = strlen(s);
    int m = strlen(p);
    
    int* ret = (int*)malloc(n * sizeof(int));
    int ret_len = 0;

    int hash1[26] = { 0 };
    int hash2[26] = { 0 };
    for (int i = 0; i < m; ++i) ++hash2[p[i] - 'a']; 

    for (int left = 0, right = 0; right < n; ++right)
    {
        ++hash1[s[right] - 'a']; // 进窗口
        if (right - left + 1 > m)  // 判断
            --hash1[s[left++] - 'a'];  // 出窗口

        // 比较两个哈希表是否相同
        int flag = true;
        for (int i = 0; i < 26; ++i)
        {
            if (hash1[i] != hash2[i])
            {
                flag = false;
                break;
            }
        }

        if (flag == true) ret[ret_len++] = left;  // 更新结果
    }


    *returnSize = ret_len;
    return ret;
}
```



## 优化：更新结果的判断条件

```c
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* findAnagrams(char* s, char* p, int* returnSize) {
    int n = strlen(s);
    int m = strlen(p);
    
    int* ret = (int*)malloc(n * sizeof(int));
    int ret_len = 0;
    
    int hash1[26] = { 0 };
    int hash2[26] = { 0 };
    for (int i = 0; i < m; ++i) ++hash2[p[i] - 'a']; 
    

    int cnt = 0;  // 统计窗口中“有效字符”的个数
    for (int left = 0, right = 0; right < n; ++right)
    {
         // 进窗口+维护cnt
        ++hash1[s[right] - 'a'];
        if (hash1[s[right] - 'a'] <= hash2[s[right] - 'a']) ++cnt;

        if (right - left + 1 > m)  // 判断
        {
            // 出窗口+维护cnt
            if (hash1[s[left] - 'a'] <= hash2[s[left] - 'a'])  // 要删除的是有效字符
                --cnt;

            --hash1[s[left++] - 'a'];
        }

        if (cnt == m) ret[ret_len++] = left;  // 更新结果
    }

    *returnSize = ret_len;
    return ret;
}
```
