[17. 电话号码的字母组合](https://leetcode.cn/problems/letter-combinations-of-a-phone-number/)

给定一个仅包含数字 `2-9` 的字符串，返回所有它能表示的字母组合。答案可以按 **任意顺序** 返回。

给出数字到字母的映射如下（与电话按键相同）。注意 1 不对应任何字母。

![img](https://pic.leetcode.cn/1752723054-mfIHZs-image.png)

 

**示例 1：**

```
输入：digits = "23"
输出：["ad","ae","af","bd","be","bf","cd","ce","cf"]
```

**示例 2：**

```
输入：digits = "2"
输出：["a","b","c"]
```

 

**提示：**

- `1 <= digits.length <= 4`
- `digits[i]` 是范围 `['2', '9']` 的一个数字。



## 解法：回溯

```c
/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
char* letterMap[10] = {"", "", "abc", "def", "ghi", "jkl", "mno", "pqrs", "tuv", "wxyz"};

char* path;
int path_len;

char** ret;
int ret_len;

void dfs(char* digits, int cur)
{
    if (cur == strlen(digits))
    {
        path[path_len] = 0;
        ret[ret_len] = (char*)malloc((strlen(digits) + 1) * sizeof(char));
        strcpy(ret[ret_len], path);
        ++ret_len;

        return;
    }

    int digit = digits[cur] - '0';
    char* letter = letterMap[digit];
    int len = strlen(letter);
    for (int i = 0; i < len; ++i)
    {
        path[path_len++] = letter[i];

        dfs(digits, cur + 1);

        --path_len;
    }
}

char** letterCombinations(char* digits, int* returnSize) {
    int len = strlen(digits);
    path = (char*)malloc((len + 1) * sizeof(char));
    ret = (char**)malloc(10001 * sizeof(char*));
    path_len = ret_len = 0;

    dfs(digits, 0);

    *returnSize = ret_len;

    free(path);
    return ret;
}
```
